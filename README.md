# nekhebit.github.io

Personal site documenting the [spinflip](https://github.com/nekhebit/spinflip) project, a hydrogen line radio telescope built with an RTL-SDR dongle.

Live at [nekhebit.github.io](https://nekhebit.github.io).

## Running locally

```bash
bundle install
bundle exec jekyll serve --livereload
```

Then open [http://127.0.0.1:4000](http://127.0.0.1:4000).

## Built with

[Jekyll](https://jekyllrb.com) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme.
